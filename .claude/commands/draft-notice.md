# draft-notice

Draft a factual distribution and scope brief. Use the regulator-approved template and a human review for any actual notice. Nothing sends.

Run `npm run recall -- draft-notice EVENT`. Replace placeholders with verified records. Show returned facts and the local output path in chat. Drafts stay under drafts/ and exports under exports/. Never email, upload or publish them. For imports compare quantities, units, contacts and coverage with the original files before the actual run. For drafts, include unresolved evidence and the responsible reviewer.
