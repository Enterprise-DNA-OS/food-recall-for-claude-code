# recall

Read one complete event before writing any new record.

Run `npm run recall -- recall EVENT`. Replace placeholders with verified records. Show returned facts and the local output path in chat. Drafts stay under drafts/ and exports under exports/. Never email, upload or publish them. For imports compare quantities, units, contacts and coverage with the original files before the actual run. For drafts, include unresolved evidence and the responsible reviewer.
