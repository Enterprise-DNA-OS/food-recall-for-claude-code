# overdue-response

Find follow-up work past the operator-assigned date.

Run `npm run recall -- overdue-response`. Add `--json` when comparing records. Cite the returned identifiers and source references. Separate exercises from live events, and keep products and units separate. Never infer that missing evidence means an action happened. Read docs/compliance.md before interpreting a compliance finding.

Report the findings, owner and next recorded due date in chat. Do not send messages or change records during a read.
